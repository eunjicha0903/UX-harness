## 4. 불일치 처리

실제 결과가 기대와 다르면, 기대값이 틀렸는지 하네스가 틀렸는지 먼저 판단해 기록한다.
하네스 문제면 원인 문서(R3~R6) 또는 scripts를 고치고 같은 실행을 반복한다. 기대값 수정은 사용자 승인 후에만 한다.
