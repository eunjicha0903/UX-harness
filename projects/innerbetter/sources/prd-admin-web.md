## 1. 개요

- 목적 [확정, RV]: 직원이 상품·이미지·카테고리·지점 등 앱에 노출되는 정보를 등록·관리하고, 지점별 주문·배송 상태를 처리한다.
- 플랫폼 [확정, QA-TC]: Flutter Web, 1920×1080 기준
- 사용자 [확정]: 관리자 단일 역할 (헤더 "최고관리자님"). 권한 등급 구분 [확인 필요]
- 범위: 단일 지점. 지점 선택 UI 없음 [확정] → 다중 지점은 SRC-00 Phase 2
