## 2. 요구사항·흐름 (S2, 잠정)

- **관리자웹 22 · Professional 심사, 관리자웹 23 · 심사 상세( 개인 사업자 ) 외 1개** — 재신청 심사 이력 누적을 보여주는 화면 없음 (문제 확인)
- **관리자웹 28 · 신고 관리, 관리자웹 32 · 신고 관리 / 빈 화면** — 신고 관리 검색이 '닉네임으로 검색'뿐, 이메일 검색 없음 (문제 확인)

- **관리자웹 29 · 신고 관리/ 원문 글 확인, 관리자웹 30 · 신고 내역 확인/회원 정지 모달 외 1개** — '확인 완료(이상 없음)' 버튼이 '제재 없음'으로 바뀌어 있음 (사람 판단 필요)
- **관리자웹 13 · 포럼 관리** — 포럼 관리 '기존 항목 유지'는 비교할 이전 시안이 없어 판단 불가 (자료 부족)

- **관리자웹 16 · 상세 / 원문 글 삭제 모달, 관리자웹 17 · 상세 / 원문 글 삭제 모달 외 3개** — 관리자가 삭제한 원문글·답글을 앱에서 어떻게 보여줄지 화면 없음 (문제 확인)
- **관리자웹 03 · 뉴스 관리, 관리자웹 04 · 뉴스 등록 상세 외 2개** — 뉴스 전체 푸시가 앱 알림 목록에 어떤 형태로 쌓이는지 정해지지 않음 (사람 판단 필요)
- **관리자웹 03 · 뉴스 관리, 관리자웹 04 · 뉴스 등록 상세 외 3개** — 앱·관리자 목록은 뉴스 이미지 여러 장인데 등록 화면은 1칸만 보임 (사람 판단 필요)

- **관리자웹 16 · 상세 / 원문 글 삭제 모달, 사용자앱 55 · 삭제 모달(원문 글/답글)** — 앱 본인 원문글 삭제 모달에는 '답글도 삭제' 안내가 없음 (사람 판단 필요)
