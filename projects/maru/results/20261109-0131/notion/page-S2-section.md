## 2. 요구사항·흐름 (S2, 잠정)
### 수정사항 반영 — ⚠ 검토 필요 6건 / 29건 — 문제 확인 0 · 사람 판단 필요 5 · 자료 부족 1
*관리자웹 수정사항을 제대로 반영했는가*
- **관리자웹 03 · 뉴스 관리** — 뉴스 푸시 상태 문구는 디자이너가 '클라이언트 html 명칭'으로 픽스했으나 그 html이 자료에 없어 일치 여부를 확인할 수 없음 (사람 판단 필요)
- **관리자웹 07 · 뉴스 수정 상세, 관리자웹 16 · 푸시 알림 재전송 (1차 때, 푸시 알림 미체크 했을 때만)** — 푸시 재전송 화면은 체크박스 비활성으로 '2차 전송 불가'를 보여 주지만 TAG 설명과 반대로 읽히고 비활성 이유 안내가 없음 (사람 판단 필요)
- **관리자웹 24 · 원문 확인 상세 / 답글 삭제 모달, 관리자웹 42 · 신고 내역 확인/제재없음 모달 외 1개** — 프레임 TAG 3곳 중 2곳은 고쳐졌고 배너 순서 변경(53)만 TAG '모달'과 화면 '토스트'가 다름 (사람 판단 필요)
- **관리자웹 40 · 신고 관리, 관리자웹 41 · 신고 관리/ 원문 글 확인 (접수 상태) 외 2개** — 신고 처리 결과 명칭 '제재 없음'은 화면끼리 일치하지만 story-service 정의('처리 완료')와 달라 정의 갱신 여부 확인 필요 (사람 판단 필요)
- **관리자웹 54 · 등록 모달, 관리자웹 55 · 수정 모달** — 배너 수정 모달은 생겼지만 배너 이미지를 바꾸는 수단(파일 선택)이 보이지 않음 (사람 판단 필요)
- **관리자웹 19 · 포럼 관리** — 포럼 관리 '기존 항목 유지'는 수정 전 원본 시안이 여전히 없어 판단할 수 없음 (자료 부족)

### 앱 크로스 체크 — ⚠ 검토 필요 16건 / 21건 — 문제 확인 8 · 사람 판단 필요 8 · 자료 부족 0
*사용자앱(모바일)과 크로스 체크했을 때 연결이 잘 되는가*
- **관리자웹 30 · Professional 심사, 관리자웹 31 · Professional 심사 외 3개** — Professional 심사 목록 태그는 '미승인'인데 드롭다운·상세는 '심사 거절'이라 3값이 일치하지 않음 (규칙 2-d) (문제 확인)
- **관리자웹 30 · Professional 심사, 관리자웹 31 · Professional 심사 외 5개** — 사용자앱은 신청 횟수(1 time·2 times)를 보여 주는데 관리자웹 심사 목록·상세에는 재신청 이력이 전혀 없음 (규칙 2-c) (문제 확인)
- **관리자웹 32 · 심사 상세( 개인 사업자 ), 관리자웹 33 · 심사 상세( 국내 사업자 ) 외 3개** — 해외 사업자 심사 상세 라벨 'Services area'가 앱 'Service area'와 다름 (나머지 라벨은 앱 신청서 변경과 일치) (문제 확인)
- **관리자웹 32 · 심사 상세( 개인 사업자 ), 관리자웹 33 · 심사 상세( 국내 사업자 ) 외 3개** — 심사 상세 예시 값이 앱 신청서와 어긋남 — 개인 'Based in'·'Experience'에 다른 항목 문장, 해외 사업자 'Registration country'가 South Korea (문제 확인)
- **관리자웹 36 · 심사 상세/ 심사 완료 (3가지 case 사업자 동일)** — 심사 거절 상세에 '신청자에게 전달한 사유'가 없어, 앱 Review feedback으로 무엇이 나갔는지 관리자가 다시 볼 수 없음 (문제 확인)
- **관리자웹 38 · 심사 거절** — 미승인 사유 모달의 '니승인' 오타는 고쳐졌지만 빈 입력에도 '확인'이 활성이라 앱 Review feedback이 빈 채로 나갈 수 있음 (문제 확인)
- **관리자웹 41 · 신고 관리/ 원문 글 확인 (접수 상태), 관리자웹 44 · 신고 관리/ 원문 글 확인 결과: 제재 없음 외 1개** — 신고 원문 확인(접수 상태)에는 신고 사유·대상이 없고, 결과 화면도 사유 1개만 보여 어떤 글·답글이 왜 신고됐는지 알 수 없음 (문제 확인)
- **관리자웹 45 · 신고 관리/ 원문 글 확인 결과: 이용 정지** — '원문 글 확인 결과: 이용 정지' 화면 제목이 '결과: 제재 없음'으로 되어 있어 44와 똑같음 (문제 확인)
