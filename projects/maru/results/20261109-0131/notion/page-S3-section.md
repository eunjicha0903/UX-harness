## 3. 컴포넌트 (S3, 잠정)
### 수정사항 반영 — ⚠ 검토 필요 2건 / 9건 — 문제 확인 2 · 사람 판단 필요 0 · 자료 부족 0
*관리자웹 수정사항을 제대로 반영했는가*
- **관리자웹 30 · Professional 심사, 관리자웹 31 · Professional 심사** — Professional 심사 목록 마지막 열 머리글이 '심사하기'라 처리된 행의 '상세보기' 버튼과 맞지 않음 (문제 확인)
- **관리자웹 44 · 신고 관리/ 원문 글 확인 결과: 제재 없음, 관리자웹 45 · 신고 관리/ 원문 글 확인 결과: 이용 정지** — 신고 원문 확인 결과(이용 정지) 화면 제목이 '결과: 제재 없음'으로 잘못 들어가 44와 내용이 같음 (문제 확인)

### 앱 크로스 체크 — ⚠ 검토 필요 10건 / 14건 — 문제 확인 4 · 사람 판단 필요 6 · 자료 부족 0
*사용자앱(모바일)과 크로스 체크했을 때 연결이 잘 되는가*
- **관리자웹 30 · Professional 심사, 관리자웹 31 · Professional 심사 외 2개** — 심사 상태 값이 목록 태그만 '미승인'이고 필터·상세·태그 컴포넌트는 '심사 거절'이라 규칙 2-d가 깨짐 (문제 확인)
- **관리자웹 32 · 심사 상세( 개인 사업자 ), 관리자웹 33 · 심사 상세( 국내 사업자 ) 외 4개** — 심사 상세 카드 예시 값이 앱 신청서와 어긋남 — Based in·Experience에 다른 항목 문장, Service area는 변경 전 값 (문제 확인)
- **관리자웹 34 · 심사 상세( 해외 사업자 )** — 해외 사업자 심사 상세 라벨 'Services area'는 오타 — 앱·다른 case는 'Service area' (문제 확인)
- **관리자웹 40 · 신고 관리, 사용자앱 60 · 게시글,답글 신고** — 앱 신고 사유 오타는 'information'으로 고쳐졌지만 관리자웹 신고 목록 2개 행에 'infomation'이 남음 (문제 확인)
- **관리자웹 19 · 포럼 관리, 관리자웹 22 · 원문 확인 상세 외 3개** — 원문 글 상세 카드가 카테고리 태그 1개 예시만 있어 앱 '최대 3개' 게시글이 상세에서 어떻게 보일지 정해지지 않음 (사람 판단 필요)
- **사용자앱 22 · 이용 정지된 회원, 관리자웹 28 · 회원 이용 정지 모달 외 3개** — 이용 정지 사유 모달에 '회원에게 그대로 보임' 안내·작성 언어·필수 입력 상태가 없음 — 앱 정지 안내 화면에 그대로 노출됨 (사람 판단 필요)
- **관리자웹 30 · Professional 심사, 관리자웹 31 · Professional 심사 외 4개** — 신청 유형 '개인 사업자'가 앱 'Individual professional'(개인 명의 신청)과 의미가 달라 명칭 확정이 필요함 (사람 판단 필요)
- **관리자웹 30 · Professional 심사, 관리자웹 31 · Professional 심사 외 2개** — '현재 회원 유형' 열 예시 값이 앱의 '승인 전까지 유형 유지' 규칙과 맞지 않아 열 의미 확인이 필요함 (사람 판단 필요)
- 외 2건 (검토 사항 DB)

### 고려 못한 사항 — ⚠ 검토 필요 10건 / 18건 — 문제 확인 3 · 사람 판단 필요 6 · 자료 부족 1
*고려하지 못한 사항이 있는가*
- **관리자웹 19 · 포럼 관리, 관리자웹 26 · 회원 관리 외 3개** — 드롭다운 목록에 '전체'가 모두 생겼으나 회원 이용 정지 모달 화면만 기본 라벨이 '전체'로 26과 다름 (문제 확인)
- **관리자웹 28 · 회원 이용 정지 모달, 관리자웹 38 · 심사 거절 외 1개** — 사유 입력 모달 3종이 여전히 컴포넌트가 아닌 프레임이고 심사 미승인 모달만 크기가 다름 (문제 확인)
- **관리자웹 39 · Professional 심사/빈 화면** — Professional 심사 빈 화면이 심사 상세 상단(제목·목록으로·미승인·승인)을 복사해 쓰고 문구도 'professional 등급'으로 남음 (문제 확인)

- **관리자웹 17 · 뉴스 관리/ 빈화면, 관리자웹 25 · 포럼 관리/ 빈 화면 외 5개** — 빈 화면은 결정대로 목록 카드 복사본을 유지했으나 Professional 심사 빈 화면에서 복사 오류가 실제로 생김 (사람 판단 필요)
- **관리자웹 18 · 검색 결과 없음, 관리자웹 19 · 포럼 관리 외 4개** — 검색 결과 없음 컴포넌트는 추가됐으나 search bar·dropdown에 지우기·선택 완료 variant는 컴포넌트 섹션에서 확인되지 않음 (사람 판단 필요)
- **관리자웹 32 · 심사 상세( 개인 사업자 ), 관리자웹 33 · 심사 상세( 국내 사업자 ) 외 4개** — 심사 상세 상단 버튼 일부가 버튼 컴포넌트가 아닌 복사본이라 처리 후 상태 변경이 화면마다 따로 필요함 (사람 판단 필요)
- **관리자웹 40 · 신고 관리** — 신고 관리에만 처리 상태 필터 드롭다운이 여전히 없음 — 필요 여부 사람 판단 (사람 판단 필요)
